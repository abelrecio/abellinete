# Abellinete

Abellinete es una herramienta automatizada para testear proyectos de C, especialmente diseñada para los ejercicios de 42, como `libft` y `ft_printf`. Su objetivo es facilitar la corrección, validación y comprobación de estilo de código y gestión de memoria en los proyectos de C, integrando pruebas, checkeo de norminette, compilaciones estrictas y pruebas dinámicas con AddressSanitizer y Valgrind.

## ¿Qué hace Abellinete?

- Automatiza la validación de las normas de estilo (norminette).
- Compila y ejecuta los proyectos `libft` y `ft_printf` en distintos modos: normal, AddressSanitizer y Valgrind.
- Proporciona menús interactivos para seleccionar el tipo de pruebas.
- Limpia el entorno automáticamente antes de cada ejecución.
- Informa de errores de compilación, fugas de memoria y fallos de estilo.
- Permite añadir fácilmente nuevos tests personalizados.

## Estructura del Proyecto

- **abellinete.sh**: Script principal. Proporciona el menú interactivo y todas las funcionalidades de test y validación.
- **entrega/**: Carpeta donde se copian los archivos a testear y se generan los ejecutables y logs de error.
- **errores/**: Carpeta donde se almacenan los resultados de norminette y logs de errores de pruebas.
- **ft_printf/**: Contiene tests específicos y archivos relacionados con el proyecto `ft_printf`.
- **libft/**: Contiene tests y archivos relacionados con el proyecto `libft`.

> Nota: Para consultar los archivos completos de cada carpeta puedes visitar [ft_printf](https://github.com/abelrecio/abellinete/tree/master/ft_printf) y [libft](https://github.com/abelrecio/abellinete/tree/master/libft) en el repositorio.

## Instalación y uso

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/abelrecio/abellinete.git
   cd abellinete
   ```
2. **Prepara tus archivos:**
   - Copia los archivos de tu proyecto (`libft`, `ft_printf`, etc.) en la carpeta de entrega.
3. **Da permisos de ejecución al script principal:**
   ```bash
   chmod +x abellinete.sh
   ```
4. **Ejecuta Abellinete:**
   ```bash
   ./abellinete.sh
   ```

## Menús y funcionalidades principales

Al ejecutar el script, se presenta un menú con las siguientes opciones:

- **Seleccionar proyecto**: `libft` o `ft_printf`
- **Tipo de test**:
  - AddressSanitizer: Detecta errores de memoria y desbordamientos.
  - Valgrind: Analiza posibles fugas de memoria.
  - Compilación normal: Asegura que todo compila y pasa los tests.
- **Comprobación de norminette**: Verifica que el código cumple las normas de estilo de 42.
- **Limpieza automática**: Borra archivos generados de pruebas anteriores antes de cada ejecución.

## Añadir nuevos tests

Puedes añadir tus propios tests a las carpetas de test dentro de `libft` o `ft_printf`. El formato es flexible y está pensado para añadir y adaptar pruebas fácilmente.

## Dependencias

- `bash`
- `gcc`
- `norminette`
- `valgrind`
- AddressSanitizer (incluido en compiladores modernos)

## Ejemplo de flujo de uso

1. Arrastra tus archivos fuente a la carpeta `abellinete`.
2. Ejecuta `./abellinete.sh`.
3. Selecciona el proyecto y el tipo de test desde el menú.
4. Consulta los resultados y los archivos de error en la carpeta `errores`.
